Developed a multimodal AI and ML-based stress prediction system that combines daily lifestyle habits, ESP32 sensor data, and webcam-based biometric analysis to predict stress levels and provide personalized wellness insights.

Research Work
Currently working on a research paper based on this project, focusing on AI-driven stress analysis, multimodal sensing, and machine learning-based wellness prediction.

Key Features:
• Real-time Heart Rate, SpO2, and Temperature monitoring using ESP32
• Stress prediction using Machine Learning models
• Multi-Output Random Forest Regressor for physiological marker prediction
• Random Forest Classifier for stress level classification
• XGBoost and LightGBM for webcam-based biometric stress analysis
• Facial expression and posture analysis using DeepFace, MediaPipe, and OpenCV
• Daily habit tracking and wellness dashboard
• AI wellness chatbot for personalized stress-reduction guidance
• Secure data storage using Supabase with Row Level Security

Skills:
Python, FastAPI, Supabase, Machine Learning, Random Forest, XGBoost, LightGBM, OpenCV, MediaPipe, DeepFace, IoT, ESP32, Data Analytics, Computer Vision, Generative AI
